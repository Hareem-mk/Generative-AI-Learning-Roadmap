# Generative AI Learning Roadmap

An interactive, beginner-friendly roadmap for learning Generative AI from fundamentals to application development and deployment.

## Features

- Beginner, Intermediate and Advanced learning levels
- Learning-level dropdown menu
- Expandable learning topics
- Core concepts in logical order
- Hands-on practice exercises
- Expected deliverable for every topic
- Completion checkboxes
- Overall progress calculation
- Reset Progress button
- Generative AI Tools Landscape

## Learning Levels

### Beginner

Covers AI and Machine Learning basics, LLMs, transformers, diffusion models, prompting, responsible AI and Python fundamentals.

**Estimated duration:** 4–6 weeks

### Intermediate

Covers APIs, SDKs, structured outputs, embeddings, vector databases, RAG, LangChain, LlamaIndex and Gradio application development.

**Estimated duration:** 6–9 weeks

### Advanced

Covers AI agents, multimodal workflows, fine-tuning, Docker, cloud deployment, CI/CD, monitoring, security and cost management.

**Estimated duration:** 8–12 weeks
